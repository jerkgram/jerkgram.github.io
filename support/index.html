Project support

Support Jerkgram

Jerkgram is free and open source. If you find the project useful, you can voluntarily support its development.

Contributions help cover development, server and macOS infrastructure, Apple-related costs, and other technical project expenses.

Optional support · no paid feature tier

Infrastructure

What your support helps with

Jerkgram’s costs are mostly technical: environments where the client can be built, tested, distributed and kept online.

Server infrastructure

International servers for Jerkgram services, APIs, update infrastructure, development backend components, and other functionality requiring an always-on network environment.

macOS development

Full iOS development requires a macOS environment with Xcode. A persistent Apple Silicon Mac would significantly improve building, testing, and debugging Jerkgram.

Apple development & distribution

Apple Developer Program access, certificates, and other costs associated with building, testing, and distributing an iOS application.

Project infrastructure

Domains, monitoring, development services, technical storage, and other infrastructure required to maintain the project.
